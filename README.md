# lazyflow

native macos dictation app. hold right ⌥ to speak, release to paste.

uses groq whisper for transcription. works in any app — terminal, notion, whatsapp, wherever your cursor is.

## setup

1. get a free api key at [groq.com](https://groq.com)
2. open lazyflow → settings → paste your key
3. grant accessibility permission when prompted

## usage

- **hold right ⌥** — record while held, transcribes on release
- **click the mic** in the menu bar — same thing with a button

## requirements

- macos 14+
- apple silicon or intel
- groq api key (free tier is plenty)
